## 合并取舍

- 生产实现与工作流置于 `tools/embodied-news`，使用独立 Node package，避免把 SQLite 采集依赖混进 Next 前端。
- 卡片从当前 Juya checkout 的 React SSR 模板生成；生产视频适配使用固定上游副本，保留历史 renderer 的复现能力。
- 同步现行栏目契约、验收模板、MiniMax 整主题/词时间戳处理、最终声音/字幕/帧覆盖检查、句级素材绑定、封面和版本审查工具。
- 两线程原本共享独立日报目录，没有两个 Git 分支可直接合并。因此本次是把已整合的可复用代码导入 Juya，而非宣称存在历史分支合并。
- 新媒体绑定和独立封面规则应用于新制作包；10 月 23 日已接受发布包保留原版本，不追溯换封面、重渲染或重传。
- 当期事实稿、下载素材、配音缓存、视频、原始网页、浏览器/账号状态和消息池没有进入 Git。专属邮箱及全局邮箱 skill 也保留本机。
