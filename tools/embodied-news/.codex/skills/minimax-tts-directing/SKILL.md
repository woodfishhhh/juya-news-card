# MiniMax 配音校音与字幕

先读项目流程与现有文稿，确认既定音色、模型、语言、地区、上游语速和后期速度。修正读音与节奏，不擅自换音色、换模型、充值或增加加速次数。

## 文稿与校音

1. 分开保存展示文稿、朗读文本、读音规则。字幕使用原文，不显示拼音、停顿标签或替换词。检查多音字、姓名、品牌、缩写、数字、单位、英文夹读；按具体词建立字典，避免全局替换单字。
2. 使用官方结构 `pronunciation_dict: {"tone": ["处理/(chu3)(li3)"]}`。中文拼音用带声调数字的音节；轻声为 5。优先整词校正，不能仅凭汉字猜专名读音。英文可用文档支持的 IPA，但先验证实际效果。
3. 以语义连贯的段落合成，让模型保留上下文。不要将字幕每个短片段都合成为独立音频。先修改标点和句法，确有需要才在两段可朗读文本之间插入 `<#0.15#>` 之类的官方停顿标记。不能连续堆叠标记，不能使用通用 SSML 的 `break`、`phoneme` 标签。
4. 保留事实、数字和必要归属。使用 `text_normalization_mode` 时核听数字与缩写；它处理文本读法，不替代事实核验。默认让模型自然选择情绪；需要人为调整时只选当前模型文档明确支持的值，先用小样判断。

字段、限制与版本差异见 [官方参数与接入注意事项](references/official-controls.md)。首次使用或参数改变时，用 EGO 打开其中的官方链接核对当前页面，再更新项目证据；不要仅凭本文件推断新版本支持情况。

## 调用与缓存

复用用户已有 MiniMax 配置。不要从聊天复制密钥，不打印 SDK config、Authorization、Cookie、完整音频 hex 或签名下载 URL。无需为已经授权的配音再次请求批准。缺少认证时将登录交给用户。

先用包含实际难词和句式的小样，验证可解码音频、请求成功状态与词级字幕，再扩展到全文。保存小样供核听，不能把接口成功当成读音已正确。

本技能附带 `scripts/synthesize.mjs`：读取 JSON 请求，通过本机已有 `mmx-cli` 的 SDK 发送官方结构，保存 MP3、原始字幕 JSON 和无密钥回执。当前环境调用示例：

```powershell
& 'C:/Program Files/nodejs/node.exe' ./scripts/synthesize.mjs --payload ./request.json --validate
& 'C:/Program Files/nodejs/node.exe' ./scripts/synthesize.mjs --payload ./request.json --out ./voice.mp3 --region cn
```

`--validate` 离线运行，不读取认证、不发请求。`--sdk` 可显式指定已安装 SDK 的路径；默认从 `%APPDATA%/npm/node_modules/mmx-cli/dist/sdk.mjs` 加载。路径相对当前目录，实际使用时先定位技能目录或传绝对路径。

完整请求至少包含 model、text、stream=false、output_format=hex、voice_setting、audio_setting、language_boost、subtitle_enable=true、subtitle_type=word。请求示例见参考文件。缓存键覆盖完整请求（含读音、停顿、情绪、归一化、字幕粒度）和地区；命中后核对音频哈希并解码，不重复付费。已有音频但字幕下载失败时停止并恢复字幕，不盲目再次合成。

## 时间轴与字幕

- 保留提供方原始词级时间戳，先核实单位、字段和实际音频时长。将词时间与原文做完整、可追溯的匹配，处理提供方归一化后的数字和字词差异；不能把字数比例估算冒充词级对齐。
- 开头结尾只裁去实际静音，保留轻辅音和自然气口，并同步平移所有时间码。用解码后的真实样本数安排段落；后期加速时只换算一次。
- 字幕按完整意思合并，保护主谓宾、列举、专名、数字单位和英文完整词。逗号和顿号只是候选边界，不是强制切换；不留下“训练采数、”这种孤立碎片。单行容纳不下时在语义边界拆分，字号、宽度以实测为准。
- 检查全文覆盖、时间单调、无重叠、单行宽度，以及最短字幕是否过短。字幕可略跨自然微停顿，不能跨章显示上一条。

## 验收与日报接入

检查服务状态码、音频非空、完整解码、真实时长、时间戳覆盖和文字一致性。核听多音字、专名、数字、开场及跨句衔接；逐条修正仍有问题的词，不声称拼音字典保证百分百正确。最终视频再检查人声与字幕、速度和跨主题衔接；接口回执、静态脚本和可解码都不能单独证明成片效果。

具身智能日报的特定音色、开场片尾、单行字幕、无额外空档、素材时长、双语及验收入口见项目的 `reports/juya-workflow.md`、`reports/evening-workflow.md`。项目内同名技能副本应与本机版本一致；改动后用 `skill-creator/scripts/quick_validate.py` 验证两份，并核对文件哈希。
