# Collector adapter contract

This independent Node collector supplies the embodied daily message pool. It does not modify recruiting or VideoFactory rendering, publication or credentials. Only root changes shared libraries, config and CLI. Workers are leaves.

Each adapter exports `async discover(source, ctx)` and `async hydrate(candidate, source, ctx)`.

`discover` returns `{ candidates: [], issues: [], coverage: {}, nextState? }`. `ctx.state` is the last committed per-source/channel discovery checkpoint. Root commits `nextState` in the same SQLite transaction as the discovered candidates: a failed listing page must not move its checkpoint. Always re-read the current head; resume historical scans with overlap to handle inserted records. `ctx.maxPages` bounds pages per run, not lifetime coverage. Cursor state may contain opaque pagination tokens, but never cookies, authorization tokens, API keys or signed API URLs. Persisted candidates are durable retry jobs. Do not silently drop body failures. Every candidate has `id`, `url`, `title`, `publishedAt` (ISO or null), `publishedAtRaw`, `datePrecision` (`second`, `day`, `month`, `year`, `unknown`), `channelId` (default `primary`), and `metadata` for adapter-specific hydration data. Discovery should paginate within `ctx.maxPages` (default 3), record incomplete pagination in coverage, and retain every discovered eligible candidate. Do not fetch bodies in discovery unless required for listing metadata.

`hydrate` returns `{ sourceId, channelId, sourceItemId, title, url, publishedAt, publishedAtRaw, datePrecision, content, contentFormat: 'text', evidenceClass, evidence: [], authors: [], topics: [], metadata: {}, raw: { url, mediaType, content } }`. Content must be actual article text, abstract, release notes or video description/transcript, not a navigation shell or a title. Evidence entries: `{ url, kind, relation, title? }`; kind is `preprint`, `paper`, `project`, `model_card`, `repository`, `official_announcement`, `official_demo`, `independent_reporting`, `independent_validation`, `unknown`. relation is `original`, `discovery` or `supporting`. Metadata may record teleoperation/autonomy/simulation/speed/test conditions, with unknown preserved. A company claim is not independent validation.

An undated page is a failed qualification, not a fabricated publication date. Date precision must match the source. Month/year records can remain pending unless they represent an explicitly dated conference announcement; no inferred midnight as precise timestamp. Throw errors for unavailable body/date or challenge/login pages. Media items need a retrieved original evidence page. A verified firsthand interview can itself be that original record: it must identify the publisher and interviewee, contain explicit direct-interview attribution in the actual article body, and preserve the original article date. The current implementation recognizes the narrowly verified Xinhua/Galbot interview pattern; technical claims remain attributed company statements, never independent validation. Ordinary media summaries, reposts and project news still require a distinct retrieved primary source. If no original evidence can be found, retain the candidate as pending evidence, not accepted.

Shared ctx: `ctx.http.get(url, options?)` / `post(url, body, options?)` -> `{text,url,status,headers}`; throws non-2xx after bounded retries. `ctx.browser.get(url, options?)` -> same response plus rendered HTML (Playwright, no account/login). `ctx.html` exports cheerio `load`, `text(html)`, `article(html,url)` -> `{title,content,publishedAt,publishedAtRaw,datePrecision,links,authors}`, `date(value)`, `absolute(url,base)`. `ctx.now` ISO, `ctx.maxPages`, `ctx.limit` hydration count limit, `ctx.workDir` scratch directory. Context created with `createContext({workDir,maxPages,timeoutMs,retries})` from `lib/context.mjs`, and must close via `await ctx.close()`.

Workers own one adapter module, tests under their unique name, scratch `work/<group>/`, and reports `work/<group>/results.json`. No overlap. Provide real discover + hydrate samples for all assigned sources, original entry failures and alternatives, candidate/body/date/link evidence, commands and remaining limitations. Root performs database/replay/update verification. Never label written code or HTTP 200 as acceptance.
